# Aervox · Live2D Mizuki

Aervox｜思隅内置的 Live2D 示例模型「Mizuki」。资源直接跟踪在 `packages/live2d/mizuki/`，由包构建同步到桌面端和 Web 的生成目录；此目录不是 Git 子模块。

- 来源：[Live2D Inc. 官方示例模型](https://www.live2d.com/) Mizuki，由 PR #33（作者 jiyun233）引入 Aervox 项目
- 版权：模型与素材版权归 Live2D Inc. 及其原作者，使用请遵循 Live2D Cubism 许可条款；本仓库仅作演示与学习用途
- 同步边界：只替换消费端 `public/live2d/mizuki/` 子树，源文件删除会在下次构建生效，相邻自定义模型保留。
