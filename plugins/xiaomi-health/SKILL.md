# 小米运动健康技能

## 技能定位

当桌宠需要了解用户近期的精力恢复情况（如前夜睡眠是否充足、今日步数是否过少）、自适应调整今日刷题任务负荷或在疲劳时送上温和休息建议时，调用此技能。

## 可用工具与接入通道
1. **系统原生健康通道**：若在「系统设置 -> 主动感知」中配置并授权了小米健康连接，可使用原生工具 `health_get_daily_steps` 与 `health_get_sleep_summary`。
2. **MCP 服务通道**：若接入了小米运动健康 MCP 外部服务，工具将以 `mcp__xiaomi-health__*` 动态呈现。
3. **未配置提醒**：若未检测到上述通道就绪，请礼貌提示用户先在设置中完成健康数据授权。

## 伴学互动准则

1. **精力自适应学习**：如果用户睡眠不足（< 6小时）或步数极少，桌宠主动将复习强度从“冲刺模式”下调为“稳固复盘”，避免题海疲劳；
2. **正面情绪引导**：达到每日 8000 步或良好作息时，在日记或对话中给予自然温暖的夸奖。
