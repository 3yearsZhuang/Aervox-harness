# 只争朝夕 · FlowCampus 校园规划插件

第一方插件将校园日程、出发建议与出发前短任务接入思隅。它随 Aervox 构建，复用本地 SQLite、插件生命周期和现有会话；不运行独立 Next.js、FastAPI、Supabase 或第二套聊天服务。实施与证据见 [ITER-072](../../plan.md#iter-072)。

## 使用

通过 `./aervox dev web` 启动现有 API 与界面，在插件管理中确认“只争朝夕 · 校园规划”已启用。移动陪伴首页显示校园规划卡；标准工作台从任务中心进入，桌宠工作台也可通过校园卡片或导航入口打开同一管理界面。

1. 新增常用地点，在偏好中选择当前出发地点。
2. 新增带开始、结束时间和地点的具体日期日程；参加后标记已到场，取消的事件不再生成出发计划。
3. 为起点与目的地填入实测或自行估算的路线分钟数，设置出发缓冲。没有路程时仍可查看日程、地点与任务，出发时间明确不可计算。
4. 新增短任务并填写预计分钟数与优先级。规划卡给出下一站、建议出发时刻和共同空档预算内的任务组合；可完成或删除任务。
5. 在现有对话中询问下一站或出发时间，模型可调用只读 `get_campus_plan`。结构化规划是数字依据，模型只解释，不自动修改课表。

页面每分钟前台刷新，也可手动刷新；示例时间不进入默认数据。手工路程始终标明估算来源。关闭界面不会删除数据，重新打开从宿主读取。

## 数据与并发

校园业务保存在插件配置的版本化 `state` 文档，最多 64 个地点、128 个事件、128 个任务与128条路程。写入通过绑定当前插件的宿主配置 Port，复用 Schema、revision CAS 和生命周期代际，禁止插件直接访问 SQLite。界面保留编辑草稿；冲突后先重新读取并核对，再明确保存，不能盲重试覆盖另一端修改。

停用或代码缺席撤销卡片、工具和端点，既有配置保留。插件内“导出校园数据”重新读取宿主快照并下载 JSON，不包含未提交草稿；“导出分发包”仅导出安装资源，不包含校园数据。插件管理“恢复默认”清空校园配置；显式卸载按宿主规则删除配置与 Secret。需要保留日程时先启用插件并导出。缺包后的独立数据管理入口仍待宿主验收，不把数据仍在 SQLite 中当作管理能力已经完成。Secret、位置观察和轨迹不进入校园文档。

## 接口与构建

- `GET /v1/plugins/flowcampus/state`：返回校园文档、revision 与生命周期代际。
- `PUT /v1/plugins/flowcampus/state`：完整校园文档与预期版本一起保存。
- `GET /v1/plugins/flowcampus/plan`：从一次文档快照计算规划；测试可传带时区的 `at`。
- `@aervox/plugin-flowcampus/domain`：共享 Schema、类型与纯规划器。
- `@aervox/plugin-flowcampus/server`：API/工具贡献。
- `@aervox/plugin-flowcampus/ui`：受信 Vue 界面贡献。

在仓库根使用 `mise exec -- pnpm --filter @aervox/plugin-flowcampus test` 和 `./aervox ci all`。`.aervox-plugin` 分发包只携带声明与允许资源，不动态加载其中的 TypeScript/Vue 实现。

## 当前边界

本批接入现有 API Transport 的移动 Web/Android 配套界面和桌面宿主。独立 Android M0 的插件配置 Port 与原生内部命令尚需接线，不能据此宣称手机脱离 API 已完成校园闭环。真实高德、GPS、系统通知、锁屏后台刷新、周课表/调课展开、CSV/ICS 导入和3D校园地图仍待后续交付。

规划规则参考维护者的本地 `FlowCampus` 工程（`apps/api/src/flowcampus`）：出发时刻等于活动开始减路程秒数和缓冲，任务组合共同消耗空档预算。本插件用 TypeScript/Vue 重新实现并沿用验证向量，采用本目录声明的 AGPL-3.0-or-later；不复制演示库或自动导入用户数据。
