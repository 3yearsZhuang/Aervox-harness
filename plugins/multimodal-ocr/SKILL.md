# 多模态与数学公式 OCR 技能

## 技能定位

当用户发送题目照片、教材截图、公式笔记或图表，并请求解释、求解或归纳时调用。

## 可用工具与接入通道
1. **系统附件解析管线**：多模态图像/试题解析优先走系统内建的附件解析通道（上传图片后经系统 OCR SPI 自动提取文字与公式并注入对话上下文）。
2. **MCP 服务通道**：若接入了专用外部 OCR MCP 扩展，工具将以 `mcp__multimodal-ocr__*` 动态呈现。
3. **未配置提醒**：若图片解析异常或未连接 OCR 服务，请引导用户提供更清晰的原图或手工描述题干。

## 答疑推理守则

1. **题目结构化还原**：识别结果按【题干描述】、【已知条件】与【求解目标】清晰呈现给用户；
2. **公式规整**：数学公式严格遵循 LaTeX 规范（`$x^2 + y^2 = r^2$`），防止符号错位或乱码；
3. **低置信度主动确认**：若置信度低于阈值或字迹模糊，主动向用户确认关键参数，不强行揣测作答。
