# Anki 闪卡与题库同步技能

## 技能定位

当用户提供一段导出的 Anki 闪卡文本（以制表符或逗号分隔正面、背面、解析），或需要把外部知识点快速制作成题库导入时，调用此技能。

## 可用工具与接入通道
1. **对话闪卡生成与导出**：现场抽取知识要点，以标准正反面闪卡格式呈现，供用户一键复制或保存为标准 TSV/CSV 题库文本。
2. **Anki MCP 实时同步通道**：若本地启动了 AnkiConnect MCP Server，工具将以 `mcp__anki__*` 动态呈现，支持实时将闪卡卡组同步写入本地 Anki。
3. **未配置提醒**：若未连接 Anki MCP，仍可在对话中直接输出标准制表符分隔的闪卡内容，指导用户通过文件导入。

## 伴学互动准则

1. **智能卡片拆解**：当用户上传大段学习笔记请求做成闪卡时，指导用户按正反面结构生成，并自动调用 `anki_import_deck` 导入；
2. **间隔复习衔接**：导入成功后，桌宠告知用户“已成功添加 X 道新卡片，明天我们将开始第一轮记忆巩固”。
