## 变更

- **原因**：用户刷新页面、关闭学习抽屉或重试启动练习时，系统此前会创建新的活跃会话，导致题组和已答进度无法继续。
- **关联能力与需求**：`CAP-003`、`FR-PRC-001`、`AC-FR-PRC-001-10`。
- **恢复语义**：同一工作区和数据主体至多恢复最新的一个 `active` 练习会话。恢复响应返回创建时的题目 ID 快照、已答题目 ID、开始时间和首个未答题索引。
- **创建重试**：创建练习会话或错题重练时若已有活跃会话，返回 `200` 和既有会话；只有不存在活跃会话时才建立题组并返回 `201`。
- **安全边界**：恢复按租户过滤，不存在或跨租户的活跃会话返回 `404`；已结束会话不会被恢复；题目快照无法读取时返回冲突错误而不替换题组。
- **前端行为**：学习抽屉加载时读取活跃会话并定位到首个未答题；所有题已答但尚未结束时，提示用户生成报告。

## 验证与回滚

- **验证**：`getPracticeSessionProgress` 单元测试覆盖重复作答去重、首个未答题、全部已答与空题组；集成测试覆盖固定题组快照、已答进度、重复启动复用、租户隔离和结束后不可恢复；OpenAPI 声明创建返回的 `200/201` 与活跃会话查询端点；工作台类型检查覆盖恢复状态。
- **回滚**：移除活跃会话查询和前端恢复入口，恢复创建会话始终返回 `201` 的行为；不删除已创建会话或作答事实。
