## 变更

- **原因**：错题本需要提供移除能力，但 `QuestionAttempt` 是不可变学习事实，物理删除会破坏历史、掌握度与复习项的可追溯性。
- **关联能力与需求**：`CAP-004`、`FR-PRC-001`、`DATA-DEL-001`、`SEC-TEN-001`。
- **目标行为**：用户可将错题标记为 `dismissed`，它不再出现在默认列表，也不能进入错题重练；用户可恢复该条目。忽略和恢复仅改变错题本可见性，不修改原始作答、知识点统计或已创建复习项。
- **范围外**：删除题目、删除作答事实、修改判定结论、批量忽略和跨工作区共享忽略状态。

## 验证与决策

- **数据**：以 `(workspaceId, subjectUserId, questionId)` 唯一的用户处置记录保存 `dismissed` 状态；恢复后切回 `active`。
- **测试**：覆盖忽略后的默认列表与重练排除、恢复、重复操作幂等、跨租户隔离，以及作答历史仍可查询。
- **决策**：Review Candidate。实现完成后以 API 集成测试、数据库迁移验证和 UI 冒烟作为 Ready 评审证据。
