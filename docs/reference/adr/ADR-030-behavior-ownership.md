# ADR-030 共享行为所有权与可替换接口

## 背景

维护者批准解耦与重复实现审计的深度整改方案。已有包边界与模块公开入口能阻断私有导入，但桌面流传输、Adapter 执行、工具审批、日记模型解析和数据库恢复仍各有平行实现，形成行为差异。需要统一规则所有者，同时保留本地单用户、SQLite 真源、独立 Core 与 API/Worker 共享产品装配。

## 备选方案

- 仅移动文件或增加类型接口：不能消除取消、授权、事务及协议规则的多处维护。
- 拆成独立服务或引入另一套 Agent 运行时：增加状态和部署所有权，不解决现有重复。
- 共享应用用例与生命周期、平台和存储作为适配器：采用；允许同步迁移内部消费者并删除过渡接口。

## 决策

1. Turn 的 HTTP 创建、认证、事件解析、补读、终态和错误判定由无 Vue 的共享客户端负责。Electron 主进程持有凭据和受信 sender 生命周期；IPC 使用有类型的观察命令，不能以任意 URL 放开访问。请求关联标识与业务幂等键分离。
2. 界面共享无视觉的会话控制器。等待输入、等待审批、执行完成和观察失败分别表达；断开观察不等于取消服务端执行。不同根界面保留各自布局与受限能力的可执行接续入口。
3. 会话对外只提供命令和查询 Port；HTTP、Bot、Worker 与插件不掌握具体 SQLite 仓储或完整执行依赖。创建分支和记录作答由领域事务命令负责幂等、来源及继承规则。
4. Native 与进程外 Adapter 共用 Attempt 领取、心跳、取消、删除门禁、fencing 和原子终态。Adapter 保留自己的循环；未知副作用不能重放。Core 保持零运行时依赖与 Apache-2.0 边界。
5. 工具来源转换为统一绑定，宿主唯一授权策略处理产品权限；Core 保留通用执行检查。插件绑定及审批关联代际与修订，停用再启用不能复活旧调用。贡献整批激活，投影和定义具有宿主实例与所有者身份，关闭或替换时释放。
6. Provider 协议、默认配置与创建属于模型基础设施；日记和主动回复只消费生成端口。日记周期、正文、版本、Outbox 与调度游标由同一发布事务提交。进程组合根解析配置快照，业务执行不反复读取整份 API 环境。
7. 当前目标数据库结构由 Schema 编译，完整物理比对和版本指纹共同守卫。旧库不通过启动时隐式修正；结构不一致先拒绝，迁移在独立 staging 构建并校验，脏数据列明后阻断。旧原地快照恢复退出公共入口，派生表不作为逻辑事实备份。
8. 同步发现、握手和传输归显式启用的同步包，经 Changeset Port 访问数据；进程 IPC 归协调包。仓储只实现数据适配，不默认导出探索性网络能力。静态资产由消费宿主拥有构建输出。
9. 架构守卫共享导入解析，检查批准依赖边及包含类型的循环；行为一致性由跨传输、驱动与工具来源的合同测试验证。相同声明名称不能单独证明 DTO 一致，网络类型从共享 Schema 派生。

## 后果与回退

内部公共接口允许统一迁移，不维持两套长期适配层。HTTP/SSE 的既有线协议、合法 JSON 审批哈希、本地数据所有权和恢复限制保持兼容。现有 API/Worker 完整产品装配继续共享，不为去除 Worker 的 Fastify 成本复制产品能力。

代码回退需同时恢复相关调用者和包依赖。数据库完成新结构迁移后，回退程序必须使用停写前的完整回滚包；禁止以旧程序直接打开已迁移库或让新旧 WAL 混用。迁移、实机与发行验证独立于代码实现，实施顺序和证据只在 [当前计划](../../../plan.md) 与 PR 中维护。

## 验证与证据

覆盖 Token/IPC、提前 EOF、幂等重试、补读与背压；Native/Adapter 取消、续租与原子终态；工具来源授权矩阵、插件跨代撤权和多宿主隔离；领域命令故障回滚；完整结构比对、关系恢复与失败后源库不变。每批运行定向回归，最终执行全量门禁；测试不替代真实设备、签名或生产迁移验收。
