# ADR-023 隔离 HLS 研究执行边界

<a id="cr-057"></a>

## 背景与决策

本记录承接原 CR-057：维护者于 2026-09-29 在 GPU/Vitis 尚未配置时批准独立研究执行器与可复现实验基础设施。研究问题是同模型条件下，Vitis 反馈与固定技能能否提高可综合代码通过率，同时控制成本。

执行器位于 `scripts/hls-agent/`，消费 [ADR-021](ADR-021-aervox-core-standalone-package.md) 的公开内核/Provider 端口；不复制 Loop，不另建 API 或数据库，不改变默认应用启动，不注册产品 CAP。后续产品化需真实需求、独立范围与模块决策，不能由研究实现自动推导。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 复用公开内核的独立研究 CLI | 采用；可以隔离环境、预算及证据，保持产品运行责任不变 |
| 接入整个桌面产品后再实验 | 首轮拒绝；引入无关 UI、数据与插件生命周期成本 |
| 复制另一个执行循环或让模型运行任意 Shell | 拒绝；丢失控制/协议回归与可信执行边界 |

## 不变量

1. 裸跑仅发送题目一次，无工具、技能或隐式重试；Agent 使用固定工具与实验技能。两者共用模型、量化、采样和上下文配置，实际资源消耗单独记录。
2. 模型仅访问显式回环端点并拒绝重定向；远程环境经用户配置的 SSH 本地转发。配置不持有明文凭据，日志不保存授权头。
3. Vitis 仅通过显式指定且本地已存在的容器镜像运行，禁网、只读根目录、最小挂载、资源限额和强制清理。生成代码不在宿主执行；公开测试只读，私有评分器和参考实现不进入容器或模型上下文。
4. 每题及独立样本使用新目录、新上下文、截止时间和执行状态；保留候选、配置/运行时哈希、工具原始报告及最终结果。失败、超时、环境失败和缺失结果保留在固定分母中。
5. 开发预算不冒充官方参数；字节预算不冒充 Token。模拟 HTTP/EDA 仅证明合同，必须标识且不得与真实实验混算。官方完整分级评分仍由外部评测系统持有。
6. 多轮 assistant 历史保留完整工具调用及逐消息推理，结果逐项配对；Provider 不跨请求共享历史。协议合同维护在[执行规范](../agent-harness-loop.md#8-provider-调用)，研究工具不支持跨进程续跑。

## 验证与限制

双入口、四组对照、容器适配和证据汇总已有实现与合同测试，[PR #255](https://github.com/3yearsZhuang/Aervox-harness/pull/255) 保留合流及协议修复证据。验证须检查一次裸跑、真实 HTTP 多轮配对、取消/超时/资源清理、重复候选、只读夹具、独立样本和固定分母；缺失模型或 Vitis 明确报告环境不可用。

真实模型/Vitis/GPU、官方 ABI 与评分、独立留出题收益、目标环境断网复现、许可兼容及实际峰值仍须分别验收。宿主产物目录没有内建磁盘配额，真实实验须使用有配额的专用文件系统。产物未提供加密、跨进程恢复或防人为篡改账本，强制退出后保留缺失样本，重跑使用新目录。

这些证据未齐不能把 ITER-021 整项标为完成，不能自动进入 ITER-022、采购、微调、正式赛事提交或产品发布。运行步骤和 H/S/M 条件验收只维护在[运行指南](../../how-to/run-hls-agent.md)，赛规来源与实验原理见[HLS 实验设计](../../explanation/hls-agent-competition-plan.md)。

## 后果与回退

研究环境可独立失败或退出，不影响产品数据库与默认启动；代价是单独管理工具链、资源和离线复现。停止研究命令、回退脚本及相关协议变更即可退出，保留实验产物与负结果；协议回退必须通过既有内核回归，不进行业务数据转换。
