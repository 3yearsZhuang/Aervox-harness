# ADR-033 产品定位：主动个人助手，学习域为首批验证切片

## 背景

2026-11-02 维护者确认：产品已从“学习助手”形态转为**陪伴与助手形态的主动智能个人助手**（“属于你的贾维斯，或者属于你的爱弥斯”）。桌宠与工作台是入口，学习最早被选定作为可测量的验证场景；这不表示其用户效果已经得到验证。2026-11-06 接续整合产品基线与下一阶段计划。

但当时的文档仍把学习写成产品本体，且相互矛盾：

- [README](../../../README.md) 与 [DESIGN](../DESIGN.md) 已采用助手定位，并说明“学习与复习是其中一项能力”；
- [PRD](../PRD.md) 仍以“正在学习编程的初学者”定义首发用户，以学习闭环作为唯一核心假设，以 WELS（每周有效学习会话数）作为北极星，核心场景 A～J 全部是学习场景，阶段命名包含“学习深化”；
- [SRS](../SRS.md) 的 P0 需求与首页五入口（伴学主体、继续学习、今日复习、学习记录、每日日记）同样只描述学习切片。

结果是：新读者读 PRD 会认为这是一个学习工具，而读 README 会认为是个人助手。定位不清会直接影响功能取舍、指标口径与新贡献者的判断。

## 备选方案

1. **只改措辞，保留学习作为产品本体**：无法解决跨文档矛盾，也无法解释为何要实现日程、文件、连接等能力。
2. **重写 PRD 与 SRS 的能力和验收**：会与已交付的学习域实现、`FR-LRN`/`CAP-*` 追踪和测试契约冲突，代价远大于收益。
3. **“身份 + 域”双层结构**：身份是助手，学习是首个可测量域；保持能力与需求 ID 稳定，只调整框架、假设、场景分组、指标与阶段命名。**本决定采用此方案。**

## 决策

- **产品身份**：归属于当前操作系统用户的主动智能个人助手，服务生活、工作与学习。桌宠是入口形态，不是产品品类。
- **学习域**：首个可测量切片，保留全部 `CAP-*`、`FR-LRN`/`FR-PRC`/`FR-REV` 与验收 ID，不改名、不重编号，避免破坏追踪与测试引用。
- **目标用户**：18 岁以上个人用户；编程初学者是首批**验证样本**，不是产品边界。
- **假设分层**：`EXP-001` 属学习域；新增 `EXP-004` 首轮检验接续入口与有来源的解释建议，固定其他能力和安全防线，长期记忆继续由 `EXP-002` 单独检验。两者不可互相替代，学习域达标不能证明通用助手成立。
- **指标**：北极星改为**每周有效帮助会话数**（真实请求 → 可核对产出或明确下一步 → 用户明确确认有用并采纳）；追问、复制、模型 Completed 和工具成功不自动计数，同意图重试/修订去重。WELS 保留为学习域子指标，历史口径不与新口径合并计算；具体字典与未完成采集边界见 [PRD](../PRD.md#61-北极星指标)。
- **场景**：PRD §3 分为日常与工作（A～D）、学习域（E～L）、高权限形态（M）三组。
- **首页入口**：目标职责采用通用命名（陪伴主体、接着上次的事、今日、记录、每日日记）；现有入口接线仍须沿 ITER-053/059/061 整合，首批只使用真实会话与学习事实，其他域随对应 CAP 验收后接入，不预先占位。各端已选受信 surface 可展示角色，资源失败可降级；Android 保持现行 Material 3 和移动操作基线。

## 后果与回退

- 新功能需说明所属域；跨域能力（记忆、日记、主动建议、插件）按通用域设计，不为学习域特化。
- 本次不修改产品代码、Schema、API、测试或插件；SRS 对齐范围说明、入口职责及现行受信角色展示，需求 ID、既定学习门槛与数据/安全验收保持可追踪。
- 指标口径变化影响看板与实验预注册：旧 WELS 数据只作为学习域基线，不与新北极星直接比较；指标字典需标注版本。
- 回退须一起恢复 PRD/SRS/DESIGN、追踪与 ADR/指标版本引用，保留历史口径；本次不涉及业务数据迁移，不按旧指标回填新口径。

## 验证与证据

- 文档验证的精确候选与门禁结果由 [PR #358](https://github.com/3yearsZhuang/Aervox-harness/pull/358) 保存，不沿用原设计分支的旧结果。现行正文把学习用户定位为首批样本，WELS 保留为域指标，历史背景仍保留原措辞。
- 设计参考：[朝夕 demo](../../proposals/companion-vision-2026/miuix.html)手工切换四个示例时刻，呈现模拟空档规划、建议与日记；只用于交互讨论，不代表 Provider、数据存储、通知或后台调度已接入。
- 用户效果：本轮没有受控样本或同口径指标证据，不宣称有效帮助、学习效果或留存提升。
- 真实实现与发布状态仍以[需求追踪](../REQUIREMENTS_TRACEABILITY.md)与 PR 证据为准；本文不新增交付承诺。
