## 1. 严重度分级（与运行手册 §2 一致）

| 级别 | 定义 | 典型示例 |
|---|---|---|
| `SEV-0` | 数据大规模泄露、不可逆损坏或安全危机响应系统性失效 | 删除后数据复活、凭据泄露、危机响应失效 |
| `SEV-1` | 核心闭环大面积不可用或删除链失效 | 核心 API 大面积不可用、删除传播超 SLA |
| `SEV-2` | 局部功能或供应商降级 | 单模型降级、队列积压、局部功能异常 |
| `SEV-3` | 低影响缺陷 | 可计划修复的缺陷 |

## 3. 升级矩阵

| SEV | 首要联系人 | 响应时限 | 未响应升级 | 通报范围 |
|---|---|---|---|---|
| `SEV-0` | 安全与隐私负责人 + 技术负责人 | 15 分钟 | 技术负责人 → 产品负责人 | 全组 + 管理层 |
| `SEV-1` | 运维/平台负责人 | 30 分钟 | 技术负责人 | 值班 + 相关 Owner |
| `SEV-2` | 相关模块 Owner | 4 小时 | 技术负责人 | 值班 |
| `SEV-3` | 相关模块 Owner | 下一个工作日 | 无 | 无 |

> 响应时限为草案默认值，正式生效需技术/运维负责人批准。

## 4. 事件流程与交接

- 每次事件指定 Incident Commander、通信人与记录人；高严重度立即冻结发布（见[运行手册 §2](RUNBOOK.md#2-通用事件流程)）。
- 交接单至少包含：事件时间线、已做止损、剩余风险、待办与负责人。
- 涉及用户数据的工单不得复制完整正文（见[数据与隐私](DATA_PRIVACY.md)）。
- 演练期间的联系与审批见[演练证据模板](DRILL_TEMPLATE.md)。
