隅21:04学习模式

「能跑」和「知道为什么停」之间差一件事：你有没有看见出口。先用一个你熟悉的例子——倒计时。

先不急着写新代码。看这三行，告诉我哪一行让函数最终不再调用自己。

countdown.py 只读 
# 从 3 倒数到 0
def countdown(n):
    if n == 0:      ← 出口
        return
    print(n)
    countdown(n - 1)

countdown(3)
分层提示
提示 01 / 观察

把 countdown(3) 的参数写在纸上，每调用一次换一行。你会发现参数在变小。

提示 02 / 条件

n == 0 是唯一不再调用自己的分支。任何递归至少要有这样一个分支。

提示 03 / 结构

把「出口」和「向出口靠近的一步」分开写：出口是 n == 0，靠近出口的一步是 n - 1。缺任何一个都会无限递归。
